# 演示脚本（≤3 分钟）

目标：突出「理论 → 算法 → 反馈」的闭环。建议在浏览器全屏、标签页依次切换，配合鼠标高亮关键区域。

## 0:00 — 0:25｜开场与问题

口播：
> 华语音乐出海常被说成「文化折扣」太高，但这到底怎么衡量？我把《破茧成蝶，声动全球》这篇论文里的六个核心理论，做成了一个可以点、可以调、可以对比的策略沙盘。

操作：停留在首页，指向顶部闭环提示条「理论 → 参数 → 决策 → 反馈 → 理论验证」。

## 0:25 — 1:00｜数据仪表盘

操作：

1. 打开「数据仪表盘」，拖动时间轴从 2014 到 2026。
2. 指向地图上从中国香港、东南亚扩展到欧美、拉美的热力点。
3. 点击三亚，右侧显示 4.53 亿元文旅消费。
4. 指向下方曲线：播放量上升的同时，模型中的文化折扣从 72% 降到 22%。

口播：
> 地图和时间轴来自论文披露的巡演口径：69 城、182 场、4.24 亿美元票房。每座城市可以点开看票房、上座率和文旅消费。下面的曲线把论文里的「被听见—被喜欢—被尊重」变成可观察的指标。

## 1:00 — 2:05｜策略模拟器

操作：

1. 切到「策略模拟器」，点击第一个决策「是否参加《我是歌手》」，选择「参加顶级竞技综艺」。
2. 观察折扣曲线下降、公信力上升；右侧状态卡同步变化。
3. 连续点几步到「欧美市场：坚持中文母语还是改唱英文」，选择「坚持全中文演唱」，高亮 `-20%` 的折扣效果。
4. 再跳到「体育场巡演」选择体育场，说明预算与文旅的权衡。
5. 点击「复刻论文路径」，展示完整曲线与最终得分。

口播：
> 每个选项都是一组参数。比如参加《我是歌手》对应媒介事件理论，带来公信力和触达；坚持母语演唱对应高低语境理论，在模型里让文化折扣降低 20%——这正是论文案例的关键判断。注意体育场巡演虽然拉高文旅溢出，但预算也显著增加，模型会对超预算扣分。

## 2:05 — 2:35｜对比报告

操作：滚动到「最终对比报告」，让观众看四条路径的得分、折扣、播放量、票房和文旅消费对比。

口播：
> 论文路径、保守路径、均衡路径和你的策略被放在同一张表里。预测数字不是商业forecast，而是相对比较：它回答的是「如果相信这套理论，哪条策略更值得做」。

## 2:35 — 2:55｜知识图谱

操作：切到「知识图谱」，点击「文化折扣」节点，再点「母语演唱策略」与「本地化运营」，展示因果边。

口播：
> 最后这张图谱把理论、事件和策略连起来。点开文化折扣，可以看到母语演唱、本土 KOL、西语专辑分别怎样压低它；顶端则连接到软实力和三阶段全球化路径。

## 2:55 — 3:00｜收尾

口播：
> 这个作品的结论很简单：理论不只是解释世界的语言，也可以成为设计决策的工具。代码、数据和演示都在 GitHub 上，欢迎复刻和改造。

## 录制提示

- 使用浏览器 1440×900 或 1920×1080 窗口，关闭无关标签。
- 地图加载需要联网；若离线录制，可提前打开一次让瓦片缓存。
- 全屏录制建议 1080p / 30fps，时长控制在 2 分 50 秒左右。
- 如需静音版，可把口播做成字幕叠加，但务必保留「理论 → 算法 → 反馈」闭环提示。
